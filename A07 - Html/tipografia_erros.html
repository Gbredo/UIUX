Sistemas Tipográficos em Interfaces Web

Por Rafael Leal Martins · 12 de maio de 2025 · 8 min de leitura

O que é uma Escala Tipográfica Modular?

Uma escala tipográfica modular é um sistema em que cada tamanho de fonte é calculado a partir de um valor base e de uma razão fixa entre os degraus da escala. Ao contrário de escolhas arbitrárias de tamanho, uma escala modular garante harmonia visual e consistência ao longo de toda a interface. Os valores mais comuns de razão incluem Major Second (1.125), Major Third (1.25), Perfect Fourth (1.333) e Golden Ratio (1.618).

A escolha da razão deve ser orientada pelo contexto de uso: razões menores produzem escalas mais compactas, adequadas a interfaces densas como dashboards e tabelas de dados; razões maiores geram contrastes tipográficos mais expressivos, mais indicados para sites editoriais e de marketing.

Como calcular uma escala modular

Para construir uma escala modular, define-se um tamanho base (geralmente 1rem = 16px) e uma razão. Cada passo acima do base é calculado pela fórmula: tamanho = base × razão^n, onde n é a posição na escala. Por exemplo, com base de 1rem e razão 1.25 (Major Third), os degraus seriam: 0.64rem, 0.8rem, 1rem, 1.25rem, 1.563rem, 1.953rem, 2.441rem e 3.052rem.

A tipografia é a fundação silenciosa de todo sistema visual. Quando funciona bem, o usuário não a percebe — apenas lê com fluidez e compreende sem esforço.

Contraste e as Diretrizes WCAG

O WCAG 2.1 define critérios objetivos de contraste entre texto e fundo. O nível AA — exigido pela maioria das políticas de acessibilidade — requer razão mínima de 4.5:1 para texto normal e 3:1 para texto grande (acima de 18pt ou 14pt negrito). O nível AAA eleva esses valores para 7:1 e 4.5:1, respectivamente.

Ferramentas de verificação de contraste

Existem diversas ferramentas gratuitas para verificação de contraste. O WebAIM Contrast Checker permite inserir cores em hexadecimal e retorna a razão calculada com indicação dos níveis AA e AAA. O plugin Stark para Figma integra a verificação diretamente ao fluxo de design. O DevTools do Chrome oferece a razão de contraste ao inspecionar qualquer elemento de texto.

Sistema de Espaçamento em Base 4px

Um sistema de espaçamento consistente é tão importante quanto a escala tipográfica. A base de 4px tornou-se padrão na indústria porque é o menor valor perceptível na maioria dos monitores e resulta em múltiplos que mapeiam bem para os tamanhos de fonte mais comuns. Com uma base de 4px, os valores de espaçamento da escala seriam: 4px, 8px, 12px, 16px, 24px, 32px, 48px, 64px e 96px.
